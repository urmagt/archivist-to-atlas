# Archivist to Atlas
Obsidian plugin: converts an Archivist PC note into an Atlas VTT statblock. Install/update with BRAT (Add beta plugin -> `<your-user>/archivist-to-atlas`).

Release: bump `version` in manifest.json (and versions.json), commit, then on GitHub go to Releases -> Draft a new release, type the new version as the tag (it must equal the manifest version), and Publish. The workflow then builds and attaches main.js + manifest.json.
