# Archivist to Atlas
Obsidian plugin: converts an Archivist PC note into an Atlas VTT statblock. Install/update with BRAT (Add beta plugin -> `<your-user>/archivist-to-atlas`).

Release: bump `version` in manifest.json (and versions.json), commit, then `git tag 0.1.2 && git push --tags`. The workflow builds and attaches main.js + manifest.json. The tag must equal the manifest version.
